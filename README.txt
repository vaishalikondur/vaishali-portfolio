VAISHALI KONDUR — PORTFOLIO

FILES
- index.html: homepage
- works/: individual writing pages
- Vaishali CV.pdf: your current CV

HOW TO VIEW
1. Open index.html in Chrome/Edge.
2. Everything is local, so it works without a server.

HOW TO ADD A NEW WORK
1. Put the PDF inside the portfolio folder (or create a new .html article).
2. Copy one of the files in works/ and rename it.
3. Edit the title, type, year and article text.
4. Add a new <div class="entry"> in index.html and point its <a class="entry-title"> to the new file.
5. Save and refresh index.html.

FOR A PDF WORK
Use an entry link such as: works/my-paper.pdf
For an article, use: works/my-article.html

IMPORTANT
The uploaded CV supports the biographical, academic and skills details used on the homepage.
The reference HTML was used as the visual starting point, but the homepage has been adapted to the requested IPA pronunciation and to the writing-portfolio purpose.
